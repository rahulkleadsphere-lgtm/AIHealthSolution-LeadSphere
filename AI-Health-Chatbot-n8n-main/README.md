# SevaSetu AI - Frontend Application

Modern clinical web application and Progressive Web App (PWA) built with React 18, Vite, TypeScript, and Tailwind CSS, featuring a museum-grade Luminous White Medical Design standard.

---

## 🌟 Key Application Features

- **Clinical Command Dashboard (`/dashboard`)**: Ayushman ABHA ceramic card pass, longitudinal vital area charts, quick-action clinical matrix.
- **Precision Vitals Studio (`/vitals`)**: Live physiological telemetry tracking with multi-vital time-range filters (24h, 7d, 30d, 90d) and custom vitals logger.
- **Personal Settings & Account Control (`/profile`)**: Clinical patient demographics, live computed BMI badge with WHO categorization, 9 curated cartoon face avatars, and 2FA modal.
- **Secure Health Vault (`/health-vault`)**: Filterable clinical document repository (Lab Reports, Prescriptions, Summaries, Scans) with side-drawer inspector.
- **AI Voice & Chat Triage (`/chat`)**: Real-time multilingual voice conversation (English, Hindi, Telugu, Odia) powered by Groq LPU models.
- **Medical Report & Lab Analysis (`/analysis`)**: Ultra-fast client-side Canvas compression (<500KB) and Vision OCR interpretation.
- **National Facility Locator (`/directory`)**: Semantic search across 40,000+ national hospitals and Jan Aushadhi generic pharmacy centres.
- **Government Welfare Schemes (`/schemes`)**: Instant eligibility assessment for PM-JAY (Ayushman Bharat), BSKY, Aarogyasri, and MJPJAY.
- **Offline First-Aid Pocketbook (`/emergency`)**: Zero-network service worker cached protocols and direct 108/104 emergency phone dialers.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm
- Backend running on `http://127.0.0.1:8000`

### Installation & Launch

```powershell
cd AI-Health-Chatbot-n8n-main

# 1. Install dependencies
npm install

# 2. Start Vite dev server
npm run dev
```

* Dev Server URL: `http://localhost:5173`
* Production Build: `npm run build`
